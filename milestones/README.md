# Milestone V1 — trước cải tiến quang học

V1 là bản chụp đầy đủ của trang ngay trước thay đổi thuật toán viền V2. Các file trong `v1/` được giữ nguyên. Mở `v1/index.html` trực tiếp hoặc truy cập `/milestones/v1/` trên dev server. Đây là snapshot file, không phải Git tag vì workspace hiện không có repository Git hoạt động.

Để so sánh với bản đang phát triển, mở `/compare.html`. Để quay lại V1, lấy các file từ `v1/` làm nguồn; lưu các thay đổi hiện tại trước khi ghi đè. V1 không cần `glass-optics.js`.
